SPESE AL VOLO — micro-app PWA

FUNZIONI
- Aggiunta rapida spesa: importo, categoria, pagamento, nota
- Totale di oggi
- Totale ultimi 7 giorni
- Elenco spese recenti
- Eliminazione movimenti
- Esportazione CSV
- Dati salvati solo sul dispositivo (localStorage)
- Installabile su schermata Home
- Funzionamento offline dopo il primo caricamento

IMPORTANTE PER INSTALLARLA COME APP
Una PWA deve essere pubblicata su HTTPS. Aprire index.html direttamente come file NON consente l'installazione PWA completa.

TEST RAPIDO GRATUITO
Pubblica la cartella su un hosting HTTPS gratuito (es. GitHub Pages, Netlify, Cloudflare Pages), poi apri il link dal telefono.

ANDROID
Apri il link in Chrome. Se disponibile, usa "Installa app" o il menu ⋮ > "Aggiungi a schermata Home".

iPHONE
Apri il link in Safari > Condividi > "Aggiungi alla schermata Home".

Dopo l'installazione l'app si apre in modalità standalone, senza barra del browser.
